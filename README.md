This code provides a first-come first-serve HPC job scheduler and the scripts to evaluate the weighted wait time score for t he submitted jobs.  

To access the data, please click on the link: https://tufts.box.com/s/eymdeyo1mw2vg45xnp88u5tyey0cv8os

You may also download the data using XDMod with the help of the notebooks found on: https://github.com/ubccr/xdmod-notebooks/tree/main
